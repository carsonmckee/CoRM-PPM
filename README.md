# CoRM-PPM
This repository contains the code and data for the CoRM-PPM presented in Chapter 5. The c++ source code can be found in the folder src. In order to compile, a g++ compiler is required (see here https://code.visualstudio.com/docs/cpp/config-mingw). 

The notebooks "eeg_analysis.ipynb" and "sim_study_analysis.ipynb" contain instructions for reproducing the plots and figures for the real EEG data example and simulation study.
